# Assignment 2 – Advanced CSS: Flexbox & Grid

This project was created for Web Technologies Assignment 2.

The purpose of the assignment is to practice modern CSS layout techniques using Flexbox and CSS Grid.

## Tasks

The project includes five parts:

- Task 0 – Navigation Bar
- Task 1 – Card Row
- Task 2 – Page Layout with Grid Areas
- Task 3 – Image Gallery
- Task 4 – Portfolio Page

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid

## Project Structure

- `index.html` – Navigation Bar
- `task1.html` – Card Row
- `task2.html` – Grid Layout
- `task3.html` – Image Gallery
- `task4.html` – Portfolio Page

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the navigation bar to move between the different tasks.

## Features

- Flexbox navigation bar
- Flexible card layout
- Grid layout using grid areas
- 3-column image gallery
- Hover effects
- Portfolio page combining Flexbox and CSS Grid
